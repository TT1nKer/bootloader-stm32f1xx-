v1.5.0 - Automotive Reliability Extensions
- Automotive OTA metadata now extends `OtaMetadata_t` with VIN, authorization, statistics, and a 16-entry diagnostic log via `bsp_ota_meta_automotive.*`
- Added automotive bootloader flow (`bootloader_main_automotive.c`) that wires in the new metadata layer, multi-watchdog supervision, and CAN transport hooks
- Introduced `bsp_watchdog_automotive.*` with tiered protection levels plus upgrade/communication watchdogs that log failures into metadata
- Added `bsp_power_monitor.*` to gate upgrades on stable 12V supply, log power anomalies, and expose threshold controls for automotive safety

v1.4.1 - CAN Transport API Fixes
- Fixed CAN HAL API calls for STM32F1 compatibility
- Changed HAL_CAN_GetRxFifoMsg to HAL_CAN_GetRxMessage
- Fixed FilterFifoAssignment to FilterFIFOAssignment (capital FIFO)
- Fixed HAL_CAN_ERROR_BUSOFF to HAL_CAN_ERROR_BOF
- All CAN transport functions now use correct STM32F1 HAL API

v1.4.0 - Automotive-Grade Features Implementation
- Power Monitoring: ADC-based voltage monitoring with stability detection
- CAN Transport: J1939-style CAN OTA transport layer with fragmentation
- Digital Signatures: SHA-256 implementation + ECDSA scaffolding
- Enhanced Security: Public key storage and signature verification framework
- Conditional Compilation: Feature flags for power monitor, CAN transport, and signature verification
- Code Fixes: Fixed duplicate #endif, macro ordering, and integer division warnings

v1.2.0 - Dual-bank OTA restructure
